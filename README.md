# 8 Week SQL Challenge – Danny Ma
This repository showcases my solutions to the **Danny Ma 8 Week SQL Challenge**, where each case study focuses on solving real-world business problems using SQL.

## Project Overview
This project goes beyond just writing SQL queries. It focuses on:
* Cleaning messy, real-world datasets
* Understanding business problems and requirements
* Transforming raw data into meaningful insights
* Writing efficient, structured, and scalable SQL queries

## Repository Structure
* **Week 1 – Danny’s Diner**
  Customer spending analysis, product insights, and customer behaviour
* **Week 2 – Pizza Runner**
  Data cleaning, delivery analysis, and handling complex fields (extras & exclusions)
* **Week 3 – Foodie-Fi**
  Subscription analytics, churn analysis, and building payment logic using recursive CTEs

## Key Skills Demonstrated
* SQL (MySQL)
* Data Cleaning & Transformation
* Common Table Expressions (CTEs)
* Window Functions (LEAD, LAG, RANK)
* Recursive CTEs
* JSON Handling (`JSON_TABLE`)
* Aggregations & Joins
* Business Problem Solving

## Key Learnings
* Real-world data is rarely clean and requires significant preprocessing
* Data cleaning is often the most critical step in analysis
* Translating business problems into SQL logic is more important than syntax
* Handling semi-structured data (like comma-separated values) using JSON techniques is powerful
* Building real-world logic (like subscription billing) improves problem-solving depth
