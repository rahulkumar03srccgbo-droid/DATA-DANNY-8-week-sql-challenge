#  8 Week SQL Challenge – Danny Ma
This repository showcases my solutions to the Danny Ma 8 Week SQL Challenge, where each case study focuses on solving real-world business problems using SQL.

#   Project Overview
This project is not just about writing SQL queries — it is about:
Cleaning messy real-world data
Understanding business problems
Transforming raw data into meaningful insights
Writing efficient and structured SQL

#   Repository Structure
Week 1 – Danny’s Diner
Customer spending, product insights, and behavioural analysis
Week 2 – Pizza Runner
Data cleaning, delivery analysis, and handling complex data (extras & exclusions)

#  Key Skills Demonstrated
SQL (MySQL)
Data Cleaning & Transformation
Common Table Expressions (CTEs)
Window Functions
JSON Handling (JSON_TABLE)
Aggregations & Joins
Business Problem Solving

#  Key Learnings
Real-world data is rarely clean
Data cleaning is the most critical step in analysis
Translating business questions into SQL logic is more important than syntax
Handling semi-structured data (like comma-separated values) using JSON techniques is powerful
