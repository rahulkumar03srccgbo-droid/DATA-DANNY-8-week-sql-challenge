# 8 Week SQL Challenge – Danny Ma
This repository showcases my solutions to the **Danny Ma 8 Week SQL Challenge**, where each case study focuses on solving real-world business problems using SQL.

---
## Project Overview
This project goes beyond just writing SQL queries. It focuses on:
- Cleaning messy, real-world datasets  
- Understanding business problems and requirements  
- Transforming raw data into meaningful insights  
- Writing efficient, structured, and scalable SQL queries  

---
## Repository Structure
### Week 1 – Danny’s Diner  
Customer spending analysis, most popular items, and customer behaviour insights  

### Week 2 – Pizza Runner  
Data cleaning, delivery performance, and handling complex fields (extras & exclusions)  

### Week 3 – Foodie-Fi  
Subscription analytics, churn analysis, and recursive payment logic  

### Week 4 – Data Bank  
Customer transaction analysis, running balances, and financial metrics  

### Week 5 – Data Mart  
Before vs after analysis, sales trends, and business impact evaluation  

### Week 6 – Clique Bait  
Funnel analysis, user journey tracking, and conversion metrics  

### Week 7 – Balanced Tree  
Product hierarchy, segmentation, and revenue breakdown analysis  

### Week 8 – Fresh Segments  
Interest-based segmentation, rolling metrics, and trend analysis  

---
## Key Skills Demonstrated
- SQL (MySQL)  
- Data Cleaning & Transformation  
- Common Table Expressions (CTEs)  
- Window Functions (ROW_NUMBER, RANK, LEAD, LAG)  
- Recursive CTEs  
- JSON Handling (`JSON_TABLE`)  
- Aggregations & Joins  
- Analytical Thinking & Business Problem Solving  

---
## Key Learnings
- Real-world data is rarely clean and requires preprocessing  
- Data cleaning is often the most critical step in analysis  
- Translating business problems into SQL logic is more important than syntax  
- Advanced SQL (window functions, recursive queries) enables deeper insights  
- Structured thinking is key to solving complex analytical problems
